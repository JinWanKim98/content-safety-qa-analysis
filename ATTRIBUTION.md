# DICES attribution and handling

Source dataset: **DICES Dataset: Diversity in Conversational AI Evaluation for Safety**, Google Research datasets. Authors credited in the source: Lora Aroyo, Alex S. Taylor, Mark Diaz, Christopher M. Homan, Alicia Parrish, Greg Serapio-Garcia, Vinodkumar Prabhakaran and Ding Wang (2023).

The project preserves upstream CSV bytes and source documentation. Project code generates aggregate metadata, explicit semantic mappings and later analysis; these are derived work, not an official Google product or endorsement. The field-37 documentation discrepancy and malformed reason strings are documented without altering raw values.

Raw offensive dialogues and rater demographic records are kept out of public-facing dashboards. Use attribution and links when sharing derived outputs; indicate project transformations. The raw CSV is not included in this repository; download it from the source repository above.
